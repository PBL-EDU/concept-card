# 概念卡生成器（Concept Card）

> English documentation: [README.md](README.md)

在 Obsidian 里读文献时，选中一个**人名 / 理论 / 概念**，右键生成概念卡：

- **精简版 7 节**：快速弄懂，读完就能用；
- **完整版 10 节**：加上沿革、争议、知识连接，适合精读；
- 卡里留出**只有你能写的三块**（我的看法 / 对我的意义与行动），AI 只出追问，不替你表态；
- 卡片名唯一、按类型自动归档，并能从精简版**补全成完整版**，带 `stage`、`revisit` 生命周期字段。

> 本版是 **v3 demo（1.2.1）**：两档结构、补全、生命周期、全库判重已实现；「同名合并」「标题自动拆分」还在需求列表里。

```markdown
# 认知失调

> [!abstract] 一句话
> 信念与行为不一致时产生的不适感。

## 定义与机制

费斯汀格（Leon Festinger）1957 年提出：人需要保持内部一致……

*来源：原文*

## 例子
……

## 边界与反例
……

## 易混淆辨析
……

## 我的看法

> [!question] 待你补充
> - 我同意哪一部分？为什么？
> - 哪一部分让我迟疑——是证据不足，还是与我的经验冲突？
> - 我能举一个亲身经历支持或反驳它吗？

我的回答：

## 对我的意义与行动

> [!question] 待你补充
> - 它能解释我经历过的哪个现象？
> - 本周可以试的一件小事是什么？

我的回答：

## 自测
1. 买课后的态度变化属于什么？
2. 什么情况不算认知失调？

## 出处
- 来源：[[社会心理学读书笔记]]
- 原文片段：「认知失调」
- 生成模型：deepseek-chat
```

## 安装

1. 把 `concept-card` 文件夹（或解压 `concept-card-1.2.0.zip`）放到 `<你的库>/.obsidian/plugins/concept-card/`。
2. Obsidian → 设置 → 第三方插件 → 关闭安全模式 → 刷新。
3. 启用「概念卡生成器」。

## 配置 AI

设置 → 概念卡生成器 → AI 服务：

| 服务商 | Base URL | 常用模型 |
| --- | --- | --- |
| OpenAI | `https://api.openai.com/v1` | `gpt-4o-mini` / `gpt-4o` |
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat` |
| Ollama（本地） | `http://127.0.0.1:11434/v1` | `qwen2.5:7b` |
| 自定义 | 任意 OpenAI 兼容网关 | 按网关文档 |

填 Key → 点「测试」→ 看到 ✅ 即可。

## 怎么用

### 生成

- 选中文字 → 右键 → **生成概念卡（精简）** / **生成概念卡（完整）**
- 阅读模式同样可用（插件接管阅读视图右键；右键链接/图片/嵌入块时仍走原生行为）
- 命令面板：`生成概念卡（精简）`、`生成概念卡（完整）`、手动输入概念名

### 升级

在卡片上右键（或打开卡片后用命令 / 编辑器右键）：

- **补全为完整版（AI）**：只补缺失的 3 节，已有正文和你的留白内容一个字不动；
- **升级为完整版（空模板）**：只插入 3 个空小节，不调 AI，你自己慢慢填。

### 生命周期与复查

- **阶段建议**：打开卡片时，如果两个留白都写了（各 ≥20 字），会提示可升级；运行命令 **概念卡：按建议更新阶段** 确认（幼苗 → 成长；完整版 + 复查日已到 → 常青）。
- **复查间隔**：设置 → 复查与阶段，可分别设幼苗 / 成长 / 常青的间隔（默认 7 / 14 / 90 天）。
- **复查面板**：右侧栏「概念卡复查」（图标是学士帽，避免和日历类插件冲突），列出**全部在复查中的卡**（含未来排期），分「已到期 / 即将复查」两组，可「已复查」（顺延）或「常青」；右下角状态栏显示 `复查 到期数/总数`，点它打开面板，启动时也会提示到期数量。
- **写入今日日记**：启动/复查后，用今日到期卡片更新当天日记里的提醒块（`<!-- concept-card-review:start -->` 标记，重复执行不会重复添加；今天的日记不存在时不会自动创建）。
- **预告到复查日**：安排复查、升级、标记常青或「已复查」后，会把**该复查日那天的日记**更新/新建出来，块里列出那天到期的卡片；这样 7 天后打开日记就能看到预告。也可手动运行 **概念卡：把复查写入下次复查日的日记（预告）**。
- 日记目录 / 文件名格式留空时跟随 Obsidian Daily Notes 插件。
- 右键卡片仍可手动 **标记为常青** / **安排复查（按当前阶段）**。

## 两档结构

| # | 完整版（10 节） | 精简版（7 节） | 谁写 |
|---|---|---|---|
| 1 | 定义与机制（含“为什么重要”） | ✅ | AI |
| 2 | 例子 | ✅ | AI |
| 3 | 边界与反例 | ✅ | AI |
| 4 | 来龙去脉（按类型变：时代与生平 / 来龙去脉 / 适用条件与步骤 / 作者与背景…） | — | AI |
| 5 | 易混淆辨析 | ✅ | AI |
| 6 | 不同视角与争议 | — | AI |
| 7 | 与已有知识的连接 | — | AI |
| 8 | 我的看法 | ✅ 留白 | **你** |
| 9 | 对我的意义与行动 | ✅ 留白 | **你** |
| 10 | 自测 | ✅ | AI 出题 |

开头还有「一句话 + 原文语境」两个 callout，结尾「出处」callout（不计入节数）。

### 留白：AI 只出问题，不表态

「我的看法」「对我的意义与行动」只有固定追问和「我的回答：」空行，AI 不会写“你应该怎么看”。这些留白是卡片持续生长的入口：以后回来补一句，卡片就厚一层。

### 来源分层

每个 AI 小节末尾标来源：

- `*来源：原文*` —— 原文片段明确说了；
- `*来源：通行知识（非原文）*` —— 学科常识，原文没提；
- `*来源：AI 推断，请核对*` —— AI 的整合或推断。

提示词还要求 `quote` 逐字取自原文，不编造页码/年份。

## 归档规则

1. **根目录**：可显式勾选「概念卡放在库根目录」，根就是库根（跳过自动检测）；卡片仍会进入根下的子文件夹（自动匹配或类型映射），例如 `3.基本概念`。不勾选时优先用设置里填的路径；留空才自动扫描。
2. **子文件夹**：可开关「自动匹配子文件夹」；开启时按类型关键词在根下找现成目录（概念 → `3.基本概念`、作品 → `1..书籍、文献`），关闭时只认显式类型目录。
2. **子文件夹**：
   - 设置里每类卡片可指定目标目录（支持 `人物卡`、`3-知识/人物卡`、`/3-知识/人物` 三种写法，不存在自动创建）；
   - 留空则按类型关键词自动匹配现有子文件夹；
   - 都不匹配：回退根目录，或按类型新建（可开关）。

## 常见问题

**Q：生成很慢或失败？**
点「测试」确认 Key/地址/模型；Ollama 先 `ollama serve`。

**Q：卡片里有些内容是 AI 编的吗？**
看每节末尾的来源标记；`inference` 与 `通行知识` 都要自己核对。`confidence` 只是模型自评，不可全信。

**Q：同名概念怎么办？**
默认「打开已有」，且判重是**全库**范围：文件名、frontmatter `title`、`aliases` 任一命中都会打开已有卡（哪怕它在别的目录），不会新建第二张同名卡。要硬建第二张，把同名策略改成「加 -2 后缀」；覆盖会先备份旧卡。真正的「合并」还在需求列表 R-007。

**Q：精简版能反悔吗？**
能，右键「补全为完整版」，只插入缺失小节，不改你写的内容。

**Q：升级后我能继续改吗？**
能。之后重复点升级是幂等的，不会重复插入。

**Q：阅读模式右键被接管了？**
Obsidian 没有阅读视图菜单钩子，只能接管；设置里可关闭，改用命令/图标。

```bash
cd concept-card
npm install
npm run dev      # watch
npm run build    # 生产构建
npm run typecheck
node test/run.cjs            # 纯逻辑测试（16 项）
node test/integration.cjs    # 集成冒烟（17 项，mock obsidian 跑真实 main.js）
```
